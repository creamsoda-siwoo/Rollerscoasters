# 코스터 스튜디오

브라우저에서 롤러코스터를 설계하고 직접 타 보는 1인용 3D 게임입니다.
Three.js + Vite + TypeScript 로 만들었고, 서버 없이 동작합니다(저장은 localStorage).

**핵심 루프** — 설계 모드에서 레일을 깔고 → 탑승 모드에서 타 보고 → 기록(최고 속도, 최대 G, 탑승 시간, 스릴 점수)을 확인합니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
npm test           # 트랙·물리 단위 테스트
```

`dist/` 는 정적 파일뿐이라 아무 정적 호스팅에나 올리면 됩니다(상대 경로 빌드).

## 조작

| 동작 | 마우스 / 키보드 | 터치 |
| --- | --- | --- |

| 뱅킹 / 체인 리프트 | 오른쪽 패널의 슬라이더 / 체크박스 | 아래 패널 |

| 삭제 | `Delete` | 점 삭제 버튼 |

- 레일은 닫힌 Catmull-Rom 스플라인이며 마지막 점이 첫 점(초록색, 승강장)으로 이어집니다.
- 체인 리프트는 "이 점 → 다음 점" 구간 단위로 지정합니다(노란 점·노란 침목).
- 오른쪽 패널에 **완주 가능 여부 예측**이 실시간으로 표시되고, 못 넘는 곳에는 붉은 표식이 섭니다.
- **자동뱅킹**은 예상 통과 속도에 맞춰 모든 점의 기울기를 계산합니다.

### 탑승 모드

`C` 시점 전환(1인칭 ↔ 3인칭), `M` 소리, `R` 다시 타기, `Esc` 설계로.
속도가 모자라 오르막을 못 넘으면 실패 처리되고, "멈춘 위치 보기"로 그 지점을 바로 확인할 수 있습니다.

## 코스 JSON

코스 전체가 JSON 하나입니다. 상단 **JSON** 버튼으로 복사·파일 저장·가져오기를 할 수 있고,
localStorage 에도 같은 형식으로 들어갑니다. 다음 단계에서 서버에 그대로 저장하면 됩니다
(`src/track/storage.ts` 의 함수만 API 호출로 바꾸면 됨).

```jsonc
{
  "version": 1,
  "id": "k3f9x2ab",
  "name": "첫 번째 코스",
  "createdAt": "2026-11-15T00:00:00.000Z",
  "updatedAt": "2026-11-15T00:00:00.000Z",
  "points": [
    // 순서대로 이어지고 마지막 점은 첫 점으로 닫힘. points[0] 이 승강장.
    { "id": "a1", "x": -96, "y": 3.2, "z": 70, "bank": 0, "chain": false },
    { "id": "a2", "x": -74, "y": 3.2, "z": 70, "bank": 0, "chain": true }
  ],
  "record": null          // 현재 설계의 탑승 기록. 설계를 고치면 null 로 돌아감
}
```

- 좌표 단위는 m, `y` 가 위쪽. `bank` 는 도(°)이며 + 가 진행 방향 기준 오른쪽 기울임.
- `chain: true` 는 그 점에서 다음 점까지가 체인 리프트라는 뜻.
- `deserializeCourse()` 가 형식을 검증하고, 잘못된 입력은 읽을 수 있는 오류 메시지로 거절합니다.

## 물리 모델

열차는 트랙 위의 질점으로 다룹니다. 상태는 달린 거리 `s` 와 속력 `v` 뿐이고, 1/240초 고정 스텝마다

```
v₁² = v₀² + 2g(y₀ − y₁) − 2·a_loss·Δs        a_loss = μ·(수직 하중) + k·v²
```

로 갱신합니다. 높이 차가 그대로 속도가 되고, 구름 마찰(μ=0.012)과 공기 저항(k=0.0005/m)만큼만 잃습니다.
체인 리프트는 최소 6 m/s 를 보장하고, 승강장은 출발 10 m 동안 4 m/s 까지 밀어 줍니다.
구동 구간 밖에서 속력이 0 이 되면 실패입니다. 고정 스텝이라 같은 트랙은 항상 같은 결과가 나오며,
설계 화면의 예측과 실제 탑승 결과가 일치합니다.

G 는 `(가속도 − 중력) / g` 를 탑승자 축(위/옆/앞)으로 나눈 값입니다.
수직 −2 ~ 5.5 G, 횡 2.2 G 를 넘으면 화면 가장자리가 붉어지고 스릴 점수가 깎입니다.

## 알려진 한계

- Catmull-Rom 은 제어점에서 곡률이 불연속이라, 점 간격이 고르지 않으면 그 자리에서 G 가 잠깐 튈 수 있습니다(약 ±1 m 로 평활).
- 레일끼리의 충돌은 검사하지 않습니다. 지면 아래로 내려가는 경우만 경고합니다.
- 열차를 질점으로 계산하므로 차량 길이에 따른 효과는 반영되지 않습니다.
